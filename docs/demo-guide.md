# 两分钟MVP演示流程

演示前启动生产构建，打开首页，选择“使用内置快照”。浏览器可以关闭外部网络；不要关闭提供静态文件的本机服务。

**0–25秒：问题与数据。** 首页展示辽宁省级海洋渔业背景、长海近海示例点以及真实模型预报的获取时间与有效期。说明这套原型把标准资料变成可解释的应用工作流程。

**25–55秒：规则评估。** 打开养殖条件评估，先显示空参数均待补充，再载入基准情景。展示四项在参考范围内和对应条款。载入高温情景，温度变为26°C，系统突出该项并给出复核事项。

**55–95秒：情景比较。** 在情景推演先保存基准参数，再保存高温参数。展示四项规则下的差异和参数对照；刷新页面，情景仍保留。说明此处是参数假设的比较，不声称实际改变海水或提高产量。

**95–120秒：交付结果。** 打开报告，展示规则版本、数据来源、条款、结果和对比，导出JSON或打印版。讲清楚原创价值：资料规则化、模型/观测口径隔离、可解释判断和可复现的情景报告。

演示数据为固定测试参数与带日期的真实模型快照；不要把基准/高温方案讲成真实养殖场测量，也不要把省级统计讲成系统管理的产量。
