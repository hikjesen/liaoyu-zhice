# 原创决策模型与适用范围

## 业务问题

将地方养殖规程的四项环境条件转为可解释的逐项检查，并允许用户比较不同输入情景。原型不推断真实产量、存活率或疾病概率，不下发养殖设备指令。

## 依据

DB21/T 3719—2023《虾夷扇贝吊耳养殖技术规程》，适用辽宁沿海虾夷扇贝吊耳养殖模式。正式标准2023-04-30发布、2023-05-30实施。4.1/4.2条在下载PDF第5页（正文第1页）。

|规则|参数|参考条件|条款|软件输入单位|
|---|---|---|---|---|
|SCA-TEMP|养殖水层温度|0至24，含边界|4.2|°C|
|SCA-SAL|盐度|28至33，含边界|4.2|原文数值口径，原文未注明单位|
|SCA-DEPTH|海域水深|15至30，含边界|4.1|m|
|SCA-CURRENT|海水平均流速|不宜超过20|4.1|cm/s|

“养殖水层”是本产品为确保参数可比性设置的输入语义；原文4.2为养殖海域水温、盐度。4.1还引用DB21/T1867，4.2还引用NY5052；本原型没有将四项检查包装为对完整标准的符合性认证。

软件另设置宽松的可输入数值域，用来拦截负水深、非有限数值等错误。此数值域是界面校验配置，与标准的适宜范围分开，不是新的养殖阈值。

## 算法

对每个参数保存数值与来源。来源为用户填写、模拟情景或海面模型参考。

1. 空值：待补充。
2. 非数值、非有限数值、超出输入校验域：数值无效。
3. 口径不匹配的海面模型值：模型参考，待补充相应养殖参数。
4. 有效可比较值落在闭区间内：参考范围内；否则超出参考范围。

汇总只统计范围内、超范围、待补充项数。存在超范围时优先突出；其次展示缺失。可判定覆盖率为（范围内+超范围）/4，明确不当作安全概率。

## 参数与模型数据隔离

Open-Meteo海温是海面模型温度；海面流速是对应时刻、模型网格的输出。标准需要的海水平均流速还涉及水层与时间统计口径。即使完成 km/h→cm/s 的数值换算，也不能自动消除语义差异。因此“填入海面参考值”只辅助查看，来源为model的项永远不被记为通过。

手动编辑某个输入会转为用户填写；预置测试情景保持scenario来源。基准情景18、31、22、12，高温情景仅温度26，低盐情景仅盐度26。这些值只用于软件测试。

## 可检验的原创成果

规则化资料整理、缺失/来源/单位语义隔离、结果解释、同规则多情景比较、报告输入与规则版本回溯。算法是确定性区间规则，不宣称训练模型或科学预测能力。

## 验证

单元测试核对上下边界、超界、缺失、NaN、模型来源、输入校验和报告不可变性。浏览器测试用关闭外部网络的生产构建验证完整流程。下一阶段行业评估可由指导教师逐条复核条款映射，并用相同输入比较人工判断和系统结果；当前不编造专家验证或生产收益实验。
