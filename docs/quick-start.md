# 本机运行与演示

## 使用已编译包（推荐直接体验）

解压站点包，进入包含 `dist` 和 `scripts` 的目录，在该目录打开终端。

Windows可双击 `Start-Liaoyu.cmd`，它会寻找本机的Python或Node.js并启动站点。macOS/Linux可运行 `sh start-liaoyu.sh`。需要手动启动时，使用下面命令。

有 Node.js 时执行：

```sh
node scripts/serve.mjs dist
```

有 Python 3.8及以上时执行：

```sh
python scripts/serve.py dist
```

然后在浏览器地址栏打开 `http://127.0.0.1:4173`。静态服务只监听本机；终端保留开启，Ctrl+C结束。首次进入即可看到内置真实海况快照，无需注册或填写API密钥。不要直接双击 `dist/index.html`，浏览器会限制本地文件方式的模块加载。

## 从源码开发

Node.js 22.19.0 + pnpm10.20.0：

```sh
corepack enable
corepack prepare pnpm@10.20.0 --activate
pnpm install --frozen-lockfile
pnpm dev
```

执行 `pnpm build` 生成站点。执行 `pnpm preview --port 4173` 体验生产版本。`pnpm test` 运行规则测试。

## 常用操作

首页“更新海况”访问Open-Meteo，失败后保留已有快照，不影响其余业务。返回“使用内置快照”可恢复可重复的演示环境。

进入“养殖条件评估”，初始四项参数均为空；“载入基准情景”填入明确标注的测试参数。“载入高温情景”只把温度改为26°C，对应一项超范围。海面参考值单独标记，不自动判断为实测符合条件。

“情景推演”保存最多五份方案，刷新后仍保留在同一浏览器。不同设备或清除浏览器数据后记录不共享。报告页“导出JSON”可备份当前输入及情景数据；评估页“导入报告JSON”恢复当前输入并重新计算，不自动覆盖已保存的情景。

报告页“打印 / 保存PDF”调用浏览器打印。选A4纸，建议打开背景图形，关闭浏览器页眉页脚；系统会隐藏导航栏和操作按钮。

## 部署

`dist/` 可部署在静态网站服务。使用相对资源路径和Hash路由，无需后端重写。未经项目负责人同意，不要改变私人仓库可见性或上线公开网站。当前MVP无需生产服务器上的数据库和常驻业务进程。
